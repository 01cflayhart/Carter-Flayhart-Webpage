# Sports hub extension

Mode: Operate. Existing site/site.css is visual authority; this extends rather than replaces it. User approved preserving the academic design and connection-ready empty states.

## Direction contract
THESIS: A transparent daily research board, not a tipster’s sales page. Every selection belongs to a dated sportsbook slate and an auditable model version.

OWN-WORLD: Existing slate, ivory, ice blue, Georgia headings and system body text. Prop Hunt adds a small authored field/target SVG and “Find the opportunity” language. Upset Alert uses the user-requested bell and amber risk classifications, never guarantees.

STORY: Choose a tool, book and date; inspect probability and evidence; then compare settled performance. Unavailable inputs remain explicitly unavailable.

FIRST VIEWPORT: Shared academic identity and navigation; tool heading, experimental warning, sportsbook/date controls and a data-state message. Below are distinct top/safe boards or favorite categories, then performance and methods.

FORM: Brief-pinned extension of existing hub and standard dashboard controls; no new visual world or concept roll. seed: none (brief-pinned).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
