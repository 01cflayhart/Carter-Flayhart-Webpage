Methods, sources & what’s missing

A qualifying price is only a screen. A dated independent pregame projection, model version and supporting evidence are required to classify a favorite. Market-implied probabilities are not relabeled as independent model forecasts. Projections must use verified team/player identities, matchup context and availability appropriate to the sport.

Daily review measures outcomes and Brier scores against frozen forecasts and flags calibration gaps. Model changes require chronological holdout evaluation and a new version; yesterday’s result never changes yesterday’s probability.

Odds connection: The Odds API (free tier requires signup; tennis tournaments and sportsbook coverage vary). Independent matchup projections and verified final results are not yet connected. Missing coverage is disclosed rather than filled with guesses.
